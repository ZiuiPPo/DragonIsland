# 奶娃菜谱与料理台

入口：侧边栏「菜谱 / 料理台」图标，是料理台的唯一入口。
建筑按钮现在打开「建筑」中心（农田/鸡舍），料理台仍只有菜谱按钮一个入口。
左侧是当前真实仓库（原料/食物切页），中间是工作台，右侧选择菜谱。

| 菜品 | 配方 | 产量 | 每份恢复饱腹值 |
| --- | --- | --- | --- |
| 瞪眼蛋包 | 小麦×2 + 鸡蛋×1 | 2 | 40 |
| 疯笑番茄蛋 | 番茄×2 + 鸡蛋×2 | 2 | 55 |
| 呆呆蔬菜沙拉 | 番茄×1 + 玉米×1 + 南瓜×1 | 2 | 45 |
| 歪嘴南瓜锅 | 南瓜×2 + 鸡蛋×1 | 2 | 65 |
| 爆笑鸡蛋布丁 | 鸡蛋×2 + 小麦×2 | 2 | 70 |

## 操作

1. 右侧选择菜谱，自动切到优先所需的仓库页。
2. 从左边将材料拖到中间对应材料格，整堆拖入时自动截取配方需要的数量。
3. 也可按「按菜谱备料」一次填入准确数量。
4. 投料仅是预览：右键材料格撤回一个，「清空投料」全部撤回，关窗或换菜谱不损失物品。
5. 点击「开始合成」时一次性扣除材料、加入成品。材料不足或食物仓库空间不足则不扣物品。
6. 成品自动进入食物页；关窗后可以继续用侧边栏仓库拖拽成品喂奶龙。
7. 右上角「关闭」或 Esc 退出。打开料理台不停止农场时间。

## 数据与协作

- 配方资源：`data/recipes/*.tres`，脚本 `scripts/data/recipe_data.gd`。
- 成品资源：`data/items/*.tres`，Category.DISH、is_edible=true，接入现有喂食与存档。
- 图标：`assets/icons/dishes/*.png`，64×64 透明像素图，根据奶龙表情参考图生成并打包。
- 配方材料用 Dictionary（物品 ID → 数量），数量固定且与投料顺序无关。
- 合成由 Inventory.exchange 执行，验证全部材料及容量后再统一更新、统一通知。
- 现有原料和食物的 ID 与字段保持兼容。新游戏补充鸡蛋 6 供开局烹饪。
- 投料预览不进存档；实际成品与材料走原有库存存档。
