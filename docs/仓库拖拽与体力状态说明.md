# 仓库拖拽与奶蛙体力状态（master 本地改动）

本次仅移植库存、拖拽喂食与状态表现，不合入农场管理分支的种植、岗位或地图改动。

## 操作与规则

- 左键拖整堆，Shift + 左键拖半堆（向上取整），右键拖一个。
- 拖到空格拆堆，拖到同类格合堆，单格最多 64 或物品配置上限；数量守恒。
- 拖到奶蛙身上消耗源格的一份食物，恢复体力；种子不可喂，满体力不再消耗。
- 体力与饱腹共用 `StaffMember.satiety`（0–100），避免两套数值不同步。
- 未工作且有体力：随机漫游；累计走动随机 5–12 秒后停下大笑，播放 `assets/audio/nailong_laugh.mp3`，每次大笑随机持续 2–5 秒，到时停止音频并继续漫游。笑脸帧随机切换，仅实际大笑期间每秒消耗 2 点体力。
- 体力为 0：优先悲伤，原地不动；喂食恢复后按当前工作状态继续。
- 工作时不播放闲置大笑，也不消耗大笑体力。
- 只在农场场景消耗，主菜单不消耗；库存、格子布局、体力、工作标志随存档保存。
- 主线暂无生产系统，新游戏赠送小麦 12、番茄 8，方便体验喂食；旧主线存档缺库存字段时使用初始库存。

## 给岗位模块的接口

`StaffRegistry.set_working(member_id, true)`：开始工作。
`StaffRegistry.set_working(member_id, false)`：停止工作，恢复随机漫游与偶发大笑。

当前 master 无实际岗位调度，本改动不伪造工作任务。工作中的角色继续走现有 NPC 行为；后续岗位模块负责具体移动和工作执行。

## 显示调整

NPC 头顶仅显示上移后的“饱腹值 数值/100”，不显示进度条、饥饿文字提示或悬停喂食提示；员工状态菜单同步取消进度条。员工姓名仍按名册正常显示。


## 仓库分类与菜谱接入

仓库使用“原料 / 食物”按钮切换，每页 20 格（5 列 × 4 行）。共用 Inventory 库存与存档，切页不改数量。

- 原料：种子、小麦、生鸡蛋。不能直接喂食，留作后续生产与菜谱消耗。
- 食物：番茄、玉米、南瓜。可直接喂食恢复饱腹值。
- ItemData.is_edible 与正的 satiety_restore、非种子共同决定可直接食用。仓库、拖拽喂食、按钮喂食都调用同一判断。
- is_ingredient 独立表示能否作菜谱原料，因此可以直接吃的食物也能用于做菜。
- 未来菜谱成品配置 is_edible=true 并设置恢复值，加入 Inventory 后自动进入食物页；本次不实现菜谱合成逻辑。
- 旧存档混排布局或种子/食物布局打开后自动迁移，库存数量不变；拆堆、合堆限制在同一分类内。
- 鸡蛋继续使用已奶娃化的 assets/icons/items/egg.png，属于原料。

## 大笑收入

每名奶龙实际大笑时每秒产生 50 金币，同时每秒消耗 2 点饱腹值。多名奶龙分别累计、收入叠加；每累计一秒发放一次 50 金币，停止大笑时补发不足一秒的整数收入，小数尾数随员工存档并留到下次结算。饱腹耗尽、工作、漫游或不在农场时不产生大笑收入。金币走现有 CoinCounter 接口，继续使用 HUD 动画和金币存档。员工面板移除了底部“工作状态默认待定”说明。
